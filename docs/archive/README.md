# Archive

for services that have since been retired or redesigned (Portainer, Wazuh, the
Hyprland Lua migration, earlier repository reviews). They are kept for context
and evidence only and are not current guidance; for live procedures use
[`docs/runbooks/`](../runbooks/) and the [service inventory](../services.md).
